# 8. Export the parts list

**Start here:** [Onshape: Bill of materials](https://cad.onshape.com/help/Content/Assembly/bill_of_material.htm).

* Assembly → **BOM** → **Flattened** → Name, Quantity, Part number, Material.
* Purchased assemblies → **Show assembly only**. Check repeated parts and quantities.
* Three-dot menu → **Export to CSV**.

**Cart quantities:** Check hardware sizes and lengths before ordering.
