# 1. Set a SMART goal

**Practice targets:** use your team's measurements.

| Ask yourself                          | Cart example                              |
| ------------------------------------- | ----------------------------------------- |
| **Specific:** What are we making?     | A folding robot cart                      |
| **Measurable:** What proves it works? | Carries 125 lb; packs within 18 in high   |
| **Achievable:** Can we make it?       | Bolted/riveted parts using our shop tools |
| **Relevant:** Who needs it?           | Students moving the robot and gear        |
| **Time-bound:** When is it due?       | November 15, 2026                         |

**Copy and fill:** By \_\_\_\_\_\_\_, we will make \_\_\_\_\_\_\_ that meets \_\_\_\_\_\_\_, checked by \_\_\_\_\_\_\_.

**Cart answer:** By November 15, 2026, build a folding robot cart that carries a 125 lb robot and packs within 18 in high. Check it with a supervised load test and packed-height measurement.
