## Remaining frame parts, guides, and guards

| Start here                                                                                       | Part                                                             | Quick recipe                                                    |
| ------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------- | --------------------------------------------------------------- |
| [FRCDesign: Frame](https://frcdesign.org/learning-course/stage1/1a/section1-exercise4/)          | Base tubes, rear posts (2 × 2), robot rails, crowns, ladder ties | Rectangle → stock dimensions → Extrude → Tube Converter → holes |
| [Onshape: Extrude](https://cad.onshape.com/help/Content/PartStudio/extrude.htm)                  | Handle bushings                                                  | Concentric circles → diameters → Extrude ring → fit check       |
| [FRCDesign: Sketch Basics](https://frcdesign.org/learning-course/stage1/1a/section1-exercise3/)  | Toolbox skids, stops, end plugs                                  | Rectangle/profile → dimensions → Extrude → clearance cuts       |
| [FRCDesign: Plate Workflow](https://frcdesign.org/learning-course/stage1/1a/section2-exercise1/) | Cradle angles and rail angles                                    | L-shaped section → dimensions → Extrude length → holes          |
| [Onshape: Extrude](https://cad.onshape.com/help/Content/PartStudio/extrude.htm)                  | Corner bumpers, panel guards                                     | Outline/circles → dimensions → Extrude → clearance cuts         |

**Colors:** match the pictures. Yellow `#FFC200`; black `#171A1E`; rubber `#121315`. Set material separately.

**Purchased parts:** supplied CAD for casters, stand feet, elbows, toolbox, batteries, and reel.
